# Доступ до пристрою

`AccessSettings` — portable-модуль defaults, валідації та збереження налаштувань.
SSID формується з MAC AP: `B-T HOME XXXX`; початковий Wi-Fi пароль `12345678`,
обліковий запис `admin / admin`. Після першого збереження defaults не перезаписують
вибір користувача. Дані Wi-Fi та облікового запису зберігаються одним blob із версією.

Сховище й хешування передаються через `AccessStore` та `PasswordCodec`.
Нові паролі не повертаються через HTTP; збережений вебпароль має вигляд солі та хешу.
Порожній `new_password` у `update` зберігає поточний хеш. Після помилки commit
модуль відхиляє вхід і оновлення до повторної ініціалізації, оскільки стійкість
останнього запису не підтверджена. Помилки завантаження не замінюються defaults.

Стартові виклики робить Runtime, надалі всі звернення виконує єдина HTTP-задача;
її потрібно завершити перед `deinit` цього модуля. Налаштування мережі застосовує
окремий ESP-IDF адаптер Wi-Fi.

Контракти API та інструкція: [WEB_RELAY.md](../../docs/WEB_RELAY.md).
