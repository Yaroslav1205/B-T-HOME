# Постійна напруга

`DcModule` усереднює відкалібровані мілівольти ADC за секунду, враховує коефіцієнт
дільника й передає значення через `DcSink`. Неблокувальний `DcInput` надає
накопичені дані спільного ADC; модуль не володіє драйвером і не створює задач.
Залежності від постачальника задаються явно в composition root.

[GPIO0, дільник 120 кОм / 10 кОм, OLED та перевірки](../../docs/DC_INPUT.md).
