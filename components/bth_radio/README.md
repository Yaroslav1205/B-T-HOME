# Перемикання радіорежимів

`RadioMode` — portable-модуль з явними посиланнями на Zigbee, Wi-Fi та веб.
Одночасно володіє lifecycle лише Zigbee або групи Wi-Fi → веб. Залежності
`nvs`, `access`, `relay` належать зовнішньому Runtime й не зупиняються при
перемиканні. Об'єкти дочірніх модулів мають існувати довше за `RadioMode`;
їх не можна додатково реєструвати у Runtime чи запускати окремо.

`toggle()` викликає лише задача-власник поза `tick`: завершення мережевих
задач може потребувати очікування. Помилка повертається власнику, який
зупиняє Runtime. Очищення включає частково ініціалізовану/запущену дитину.

`BootGesture` отримує логічний стан натискання й монотонний час. Брязкіт —
40 мс; коротке натискання — від 50 мс, довге — від 3000 мс. Подія формується
лише після відпускання. Затиснута при старті кнопка ігнорується до відпускання;
пауза опитування понад 250 мс скидає поточний жест, щоб не створити випадкову дію.

Host-тести: `tests/host/test_radio.cpp`. Апаратний адаптер — `BootButton`
у `bth_platform`; GPIO та полярність задаються профілем плати.
