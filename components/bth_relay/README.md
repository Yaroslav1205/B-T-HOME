# Реле

Portable `RelayController` керує станом через `RelayOutput` та `RelayStore`.
SDK, HTTP і FreeRTOS у цьому компоненті відсутні. Усі виклики серіалізує один
власник — worker `RelayService` з `bth_platform`.

`init` читає NVS через інтерфейс сховища й готує вимкнений вихід, `start` відновлює
збережений стан, `set` зберігає зміну до керування виходом. Однакові команди
ідемпотентні й не витрачають flash. `stop` вимикає вихід без зміни збереження,
`deinit` прибирає й частково отримані ресурси. Після `deinit` можна ініціалізувати
контролер знову.

Помилка commit робить збереження невизначеним; помилка GPIO робить вихід
невизначеним. Після такої помилки нові команди відхиляються до повторної
ініціалізації. `RelayState` не є доказом механічного спрацювання реле.

Повний опис інтерфейсу, перезапуску й перевірок: [WEB_RELAY.md](../../docs/WEB_RELAY.md).
