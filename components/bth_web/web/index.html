Керування реле
Режим 0 тримає реле вимкненим. Режим 2 вмикає його за підтвердженої відсутності мережі; після повернення мережі або втрати достовірних вимірів вимикає. Налаштування зберігається після перезапуску.

Zigbee

Очікуємо стан…

Для підключення реле увімкніть додавання Zigbee-пристрою на панелі MOES, потім натисніть «Сполучити».

Скидання видаляє лише прив’язку Zigbee. Стан реле та налаштування Wi-Fi зберігаються.

Графік відключень
1–12 — ваша група; 0 — вимкнути запити й показ. Типово 2. Оновлення кожні 5 хвилин при підключенні до роутера. На OLED — поточний або найближчий плановий інтервал відключення сьогодні. Джерело — офіційний канал Чернівціобленерго. Аварійні відключення можуть відрізнятися від графіка.

Звуковий сигнал
0 — без звуку. Від 1 до 86400 — короткий сигнал при зникненні мережі та повторення через заданий інтервал. Налаштування зберігається після вимкнення живлення.

Розрахунок автономності
Середній струм від акумулятора: 1000 мА = 1 А. Типово 58 мА. Впливає на прогноз часу та подальший облік розряду. Зберігається після вимкнення живлення; залишок заряду не скидається.

Налаштування доступу
До 32 байтів UTF-8. Після зміни мережі потрібно перепідключитися. 8–63 латинські символи, цифри або знаки.
Домашня мережа Wi-Fi налаштовується застосунком під час сполучення Matter.

Підключення до роутера

BOOT: коротке натискання перемикає точку → клієнт → Zigbee. Мережі перевіряються по черзі. Зміни застосуються при наступному вході в режим клієнта або після перезапуску.

Порожній SSID видаляє мережу. Для нового SSID введіть пароль або позначте мережу без пароля. Порожнє поле пароля зберігає попередній пароль лише для того самого SSID.
