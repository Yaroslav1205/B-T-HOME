# B-T HOME 0.2.2

Нова ревізія додає інтерактивний перегляд історії основної напруги та
скорочує цикл сторінок OLED.

- Історія напруги за 2 години, 1, 3 або 7 діб накопичується на пристрої.
  Для кожних 5 хвилин зберігаються середня, мінімальна й максимальна напруги.
- Графік масштабується колесом миші та жестом двома пальцями, переміщується
  перетягуванням. Додано кнопки масштабу, скидання, клавіатурне керування
  та показ значень при наведенні чи дотику. Оновлення даних зберігає масштаб.
- OLED показує основну напругу, резервну, IP-адресу та графік відключень,
  по 3 секунди. Інші сторінки й заставка тимчасово приховані; дані вебпанелі
  та розрахунки збережено.

Пакет призначено для `esp32c6_rgb8`, ESP32-C6, Zigbee + Wi-Fi, flash 4 MiB,
таблиця розділів `c6-4m-ota-v1`. З версії 0.2.1 доступне оновлення через
вебпанель. Пристроям зі старою таблицею `factory` потрібен одноразовий
[перехід через USB](https://github.com/Yaroslav1205/B-T-HOME/blob/v0.2.2/docs/OTA.md#одноразовий-перехід-через-usb).

Історія напруги зберігається в RAM і очищується після перезапуску.
Масштабування не змінює роздільність даних у 5 хвилин.

Перед випуском пройдено 10 наборів host-тестів у Windows та Linux,
4 тести пакування, браузерні перевірки Edge
з підставним API та збірку ESP32-C6 на ESP-IDF v5.4. Перевірено вигляд графіка
на широкому екрані та у вікні 360 px. Фізичне прошивання, OTA на платі та
жести на реальному телефоні не перевірялися.
