# B-T HOME 0.2.3

OLED показує сторінки в новому порядку: **основна напруга → резервна
напруга → графік відключень → IP-адреса**. Час показу кожної сторінки
збільшено з 3 до **4 секунд**. Якщо групу відключень вимкнено, сторінка
графіка прихована.

Пакет призначено для `esp32c6_rgb8`, ESP32-C6, Zigbee + Wi-Fi, flash 4 MiB,
таблиця розділів `c6-4m-ota-v1`. На пристроях із цією таблицею оновлення
доступне через вебпанель: **Оновлення прошивки → Перевірити оновлення →
Оновити прошивку**.

Перевірено 10 наборів host-тестів у Windows, зокрема порядок сторінок,
межу перемикання на 4 секунди та приховування графіка. Збірку ESP32-C6
виконано на ESP-IDF v5.4. Фізичне прошивання й OTA на платі не перевірялися.
